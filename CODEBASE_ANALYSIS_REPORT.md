## 3. Хардкодинг при наличии конфигов

### 3.1 Критичный хардкод

| Файл | Строки | Что захардкожено | Должно быть в |
|------|--------|------------------|---------------|
| `constants.py` | 95-361 | Матрица отношений NPC (270 строк!) | `npc_config.json` |
| `constants.py` | 84-89 | Информация о рангах | `progression_config.json` |
| `character.py` | 67-78 | Формулы генерации статов | `npc_config.json` |
| `character.py` | 103-127 | Расчёт max_stamina/max_health | `balance_config.json` |
| `constants.py` | 422 | DUNGEON_VISION_RADIUS = 10 | `world_config.json` |

### 3.2 Дублирование конфиг ↔ хардкод

`balance_config.json` содержит параметры, которые дублируются в других конфигах:
- `economy` → дублирует `economy_config.json`
- `npc` → дублирует `npc_config.json`
- `items` → дублирует `items_config.json`
- `ui` → дублирует `ui_config.json`

## 7. Рекомендации по рефакторингу

### 7.1 Приоритет 1 - Критичные

1. **Разделить `combat.py`:**
   - Выделить `CombatUI` (470 строк рендеринга)
   - Выделить `CombatLootHandler`

2. **Разделить `merchant.py`:**
   - Выделить `MerchantAI`
   - Выделить `MerchantGoodsGenerator`

3. **Перенести хардкод в конфиги:**
   - Матрицу отношений из `constants.py` → `npc_config.json`
   - Ранги из `constants.py` → `progression_config.json`

### 7.2 Приоритет 2 - Высокие

4. **Разделить `npc_spawner.py`:**
   - Выделить Factory классы для каждого типа NPC
   - Перенести `give_starting_items()` в `PlayerInitializer`

5. **Разделить `trade.py`:**
   - Выделить `ItemFilterSorter`
   - Выделить `TooltipRenderer`

### 7.3 Приоритет 3 - Средние

6. **Консолидировать конфиги:**
   - Удалить дублирование между `balance_config.json` и специализированными конфигами
   - Очистить мёртвые секции

7. **Исправить циклические зависимости:**
   - Использовать `TYPE_CHECKING` для импортов типов GameContext
   - Рассмотреть создание `core/base.py` для базовых типов
