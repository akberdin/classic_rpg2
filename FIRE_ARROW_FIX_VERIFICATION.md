# Верификация исправления умения "Огненная стрела"

## Проблема
Умение "Огненная стрела" не увеличивало урон с ростом интеллекта и не учитывало интеллект от экипировки.

## Исправление
Исправлено в коммите `60010a3` (merged в #460)

### Что было изменено:

#### 1. Конфигурация (skills_config.json)
Добавлены параметры для правильного масштабирования:
- `intelligence_multiplier`: 2.0
- `spirit_multiplier`: 0.2
- `base_rank_multiplier`: 1.0
- `rank_multiplier_per_rank`: 0.2

#### 2. Код умения (magic.py)
**До исправления:**
```python
# Неправильная формула - процентный множитель
base_damage = 5 * self.rank
intelligence_multiplier = 1.0 + (intelligence * 0.02)
total_damage = int(base_damage * intelligence_multiplier)
```

**После исправления:**
```python
# Правильная формула - как у других магических умений
intelligence = user.get_effective_intelligence()  # Учитывает экипировку
spirit = user.get_effective_spirit()
base_damage = base_damage_value + intelligence * intelligence_multiplier + spirit * spirit_multiplier
damage_multiplier = base_rank_multiplier + (self.rank - 1) * rank_multiplier_per_rank
total_damage = int(base_damage * damage_multiplier)
```

```

damage_multiplier = 1.0 + (Rank - 1) * 0.2
total_damage = base_damage * damage_multiplier
```
