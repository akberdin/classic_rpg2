# Classic RPG

Пошаговая RPG игра на Python и Pygame с процедурной генерацией мира.

## Особенности

- **Процедурная генерация карты** с различными биомами:
  - Вода
  - Песок
  - Равнины
  - Холмы
  - Леса

- **Локации на карте**:
  - Города (3 на карте)
  - Деревни (10 на карте)
  - Шахты (8 на карте)
  - Бандитские лагеря (6 на карте)
  - Руины (12 на карте)

- **Система характеристик** для персонажей:
  - Сила
  - Ловкость
  - Дух
  - Интеллект
  - Удача

- **Туман войны** - исследуйте мир постепенно
- **Пошаговое перемещение** по карте

## Установка

1. Убедитесь, что у вас установлен Python 3.8+

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

- **Стрелки** или **WASD** - движение персонажа
- **ESC** - выход из игры

## Структура проекта

```
classic_rpg2/
├── main.py              # Точка входа в игру
├── game/
│   ├── __init__.py
│   ├── constants.py     # Константы и настройки
│   ├── character.py     # Классы персонажей (Player, NPC)
│   ├── tile.py          # Тайлы и локации
│   ├── map.py           # Генерация и управление картой
│   ├── fog_of_war.py    # Система тумана войны
│   └── game.py          # Основной игровой цикл
├── requirements.txt
└── README.md
```
