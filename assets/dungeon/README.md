# Система тайлов подземелий

Эта папка содержит графические ассеты для системы подземелий игры.

## Структура папок

```
assets/dungeon/
├── tiles/          # Тайлы окружения (пол, стены, декорации)
└── objects/        # Интерактивные объекты (ловушки, сундуки, тайники)
```

## Спецификация тайлов

Все спрайты должны быть **64x64 пикселя** в формате PNG с прозрачностью (RGBA).

### Категория: tiles/ (Окружение)

Базовые тайлы пола и стен:
- `floor.png` - Обычный пол подземелья
- `wall.png` - Стена (непроходимая)
- `corridor.png` - Коридор
- `entrance.png` - Точка входа (зелёная)
- `exit.png` - Точка выхода (красная)

Декоративные элементы:
- `rubble.png` - Обломки и завалы (непроходимые)
- `water.png` - Вода или лужи (непроходимые)
- `bones.png` - Кости (проходимые, декор)
- `altar.png` - Алтарь (проходимый, особое место)

Для шахт:
- `ore_vein.png` - Рудная жила (проходимая, можно добывать)
- `minecart.png` - Вагонетка (непроходимая)
- `support.png` - Деревянная опора (непроходимая)

### Категория: objects/ (Интерактивные объекты)

Ловушки:
- `trap.png` - Необнаруженная ловушка (отображается как пол)
- `trap_triggered.png` - Сработавшая ловушка

Тайники и сундуки:
- `stash.png` - Обнаруженный тайник (не обыскан)
- `stash_looted.png` - Обысканный тайник
- `chest.png` - Закрытый сундук
- `chest_open.png` - Открытый сундук

Останки врагов:
- `remains.png` - Останки врага (можно обыскать)
- `remains_looted.png` - Обысканные останки

Интерактивные элементы:
- `lever.png` - Рычаг (неактивный)
- `lever_active.png` - Рычаг (активирован)
- `torch.png` - Факел (источник света)
- `door.png` - Закрытая дверь
- `door_open.png` - Открытая дверь

## Как использовать

Тайлы загружаются автоматически из конфигурации `game/config/assets_config.json`.

Если спрайт не найден, система использует fallback - цветные квадраты или простые геометрические фигуры.

## Рекомендации по созданию тайлов

1. **Стиль**: Используйте тёмные тона для подземелий, каменные текстуры
2. **Контраст**: Важные объекты (выходы, сундуки) должны быть яркими
3. **Читаемость**: Спрайты должны чётко различаться на расстоянии
4. **Масштаб**: Учитывайте, что тайлы будут масштабироваться в зависимости от разрешения
5. **Прозрачность**: Используйте альфа-канал для объектов с неправильной формой

## Конфигурация

Путь к конфигу: `game/config/assets_config.json`

Секции:
- `dungeon_tiles` - Тайлы окружения
- `dungeon_objects` - Интерактивные объекты

Пример:
```json
"dungeon_tiles": {
  "floor": "assets/dungeon/tiles/floor.png",
  "wall": "assets/dungeon/tiles/wall.png"
}
```

## Связанные файлы

Система подземелий реализована в модуле `game/dungeon/`:
- `tiles.py` - Определение типов тайлов
- `dungeon_map.py` - Карта подземелья
- `generator.py` - Процедурная генерация
- `renderer.py` - Отрисовка тайлов
- `traps.py` - Система ловушек
- `stashes.py` - Система тайников
