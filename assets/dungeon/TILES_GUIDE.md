# Спрайты тайлов подземелья

## Структура папок

```
assets/dungeon/
├── tiles/          ← Тайлы пола, стен, коридоров
└── objects/        ← Объекты (сундуки, ловушки и т.д.)
```

## Основные тайлы (приоритет)

Создайте PNG-файлы в `assets/dungeon/tiles/`:

### Обязательные:
- **floor.png** - Пол в залах/комнатах (наиболее заметный!)
- **wall.png** - Стены
- **corridor.png** - Коридоры между комнатами

### Важные:
- **entrance.png** - Точка входа в подземелье
- **exit.png** - Выход из подземелья
- **stairs_down.png** - Лестница вниз (многоуровневые подземелья)
- **stairs_up.png** - Лестница вверх

### Декоративные (опционально):
- **rubble.png** - Завалы
- **water.png** - Вода
- **bones.png** - Кости
- **altar.png** - Алтарь
- **ore_vein.png** - Рудная жила (для шахт)
- **minecart.png** - Вагонетка (для шахт)
- **support.png** - Опора (для шахт)

## Объекты подземелья

Создайте PNG-файлы в `assets/dungeon/objects/`:

- **trap.png** - Обнаруженная ловушка
- **trap_triggered.png** - Сработавшая ловушка
- **remains.png** - Останки врага
- **remains_looted.png** - Обысканные останки

## Требования к спрайтам

- **Формат:** PNG с прозрачностью (alpha-канал)
- **Размер:** Любой (рекомендуется 64x64, автомасштабируется)
- **Цвета:** Любые, поддерживается затемнение (fog of war)

## Как это работает

1. **Автозагрузка:** При запуске игры спрайты загружаются из `assets_config.json`
2. **Автомасштабирование:** Спрайты масштабируются под текущий `TILE_SIZE`
3. **Fallback:** Если файл отсутствует → отображается цветной квадрат
4. **Lighting:** Спрайты затемняются в зависимости от расстояния от игрока

## Пример: Создание базового набора

Минимальный набор для начала (3 файла):

```bash
assets/dungeon/tiles/floor.png      # Серый камень для залов
assets/dungeon/tiles/wall.png       # Тёмная стена
assets/dungeon/tiles/corridor.png   # Чуть темнее пола для коридоров
```

После создания файлов **перезапустите игру** - спрайты появятся автоматически!

## Текущее состояние

✓ Конфигурация настроена (`assets_config.json`)
✓ Загрузчик работает (`sprite_manager.py`)
✓ Рендеринг поддерживает спрайты (`renderer.py`)
✗ Файлы спрайтов отсутствуют (создайте их)

Пока спрайтов нет, используются цветные квадраты (fallback).
