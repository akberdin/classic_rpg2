# Skills Crafter

Визуальная утилита для создания и настройки умений в Classic RPG.

## Возможности

- **Визуальный редактор** - создание умений через удобный интерфейс на Tkinter
- **Все параметры** - настройка всех аспектов умения:
  - Базовая информация (ID, название, описание, категория)
  - Затраты (мана, выносливость, здоровье)
  - Требования (уровень, атрибуты, оружие)
  - Нацеливание (цель, область, дальность)
  - Урон (множители, скейлинг, криты, пробитие брони)
  - Лечение (мгновенное и по времени)
  - Статус-эффекты (яд, оглушение, горение и др.)
  - Прогрессия по рангам
  - Визуальные настройки (иконка, цвета, анимации)
- **Редактор анимации** - создание анимации из спрайтов:
  - От 1 до 8 кадров анимации
  - Настройка FPS (скорость воспроизведения)
  - Режимы воспроизведения: один раз, зацикленно, туда-обратно
  - Масштабирование спрайтов
  - Предпросмотр анимации в реальном времени с управлением
  - Перетаскивание кадров для изменения порядка
- **Импорт/Экспорт** - работа с форматом skills_config.json
- **Предпросмотр** - отображение иконок и превью JSON
- **Калькулятор урона** - расчет урона для разных параметров
- **Автогенерация описаний** - создание описаний по рангам

## Требования

- Python 3.8+
- Tkinter (обычно входит в стандартную поставку Python)
- Pillow (для работы с изображениями)

## Установка

```bash
pip install Pillow
```

Из корня проекта:

```bash
python run_skills_crafter.py
```

```bash
python -m utils.skills_crafter.launcher
```

## Использование

### Создание нового умения

1. Нажмите **Файл → Новое умение** или `Ctrl+N`
2. Заполните вкладки:
   - **Основное** - ID, название, описание, тип и категория
   - **Затраты** - стоимость маны/выносливости, кулдаун, требования
   - **Нацеливание** - тип цели, область действия, дальность
   - **Урон** - параметры урона (если умение наносит урон)
   - **Лечение** - параметры лечения (если умение лечит)
   - **Эффекты** - статус-эффекты, накладываемые умением
   - **Ранги** - система прогрессии и описания по рангам
   - **Визуал** - иконка, анимация из спрайтов, цвета, звуки
3. Сохраните: **Файл → Сохранить** или `Ctrl+S`

### Импорт из игры

1. **Файл → Импорт из skills_config.json**
2. Утилита загрузит все умения из текущей конфигурации игры

### Экспорт в игру

1. **Файл → Экспорт в skills_config.json**
2. Выберите путь для сохранения
3. Экспортированный файл можно использовать в игре

### Предпросмотр JSON

- **Инструменты → Предпросмотр JSON** - покажет JSON в двух форматах:
  - Полный формат Skills Crafter
  - Игровой формат (skills_config.json)

### Калькулятор урона

- **Инструменты → Калькулятор урона** - расчет урона для разных параметров персонажа

### Редактор анимации

Вкладка **Визуал** содержит редактор анимации умения:

1. **Загрузка спрайтов** - нажмите "Загрузить спрайты..." и выберите сразу несколько файлов (максимум 8)
2. **Управление порядком** - используйте кнопки ↑↓ для перемещения кадров в нужном порядке
3. **Замена спрайта** - кликните на кадр для замены его изображения
4. **Удаление кадров** - используйте кнопку ✕ для удаления кадра
5. **Настройка воспроизведения**:
   - FPS: скорость анимации (1-60)
   - Режим: один раз / зацикленно / туда-обратно
6. **Предпросмотр** - используйте кнопки ▶ ⏸ ◼ для управления

Поддерживаемые форматы изображений: PNG, JPG, GIF, BMP

### Отображение анимации на поле боя

Настройки в секции **"Отображение на поле боя"** определяют, как анимация умения будет отображаться в тактическом бою:

#### Типы анимации

| Тип | Описание | Пример |
|-----|----------|--------|
| **Снаряд** | Летит от кастера к цели | Стрела, огненный шар, ледяная стрела |
| **Луч** | Линия от кастера к цели | Молния, лазер |
| **Удар** | Появляется в точке попадания | Взрыв, удар молнии |
| **Область** | Покрывает зону вокруг точки | AoE заклинания |
| **На кастере** | Отображается на применяющем | Баффы, ауры |
| **На цели** | Отображается на цели | Дебаффы, проклятия |
| **Цепная** | Прыгает между целями | Цепная молния |

#### Настройки снаряда (для типа "Снаряд")

- **Скорость** - скорость полёта в пикселях/сек (50-1000)
- **Траектория** - прямая / дуга / самонаведение / волна
- **Высота дуги** - для параболической траектории
- **Авто-поворот** - спрайт поворачивается к цели
- **След** - эффект следа за снарядом

#### Настройки луча (для типа "Луч")

- **Ширина** - толщина луча в пикселях
- **Длительность** - время отображения в мс
- **Амплитуда волны** - для волнистого луча (молния)
- **Цвета** - градиент от кастера к цели
- **Свечение** - эффект свечения вокруг луча

#### Настройки области (для типа "Область")

- **Радиус** - размер в клетках поля боя
- **Форма** - круг / квадрат / конус / линия
- **Цвет и прозрачность** - заливка области
- **Пульсация** - анимированная пульсация

#### Тайминги

- **Применение урона** - когда наносится урон:
  - `on_cast` - сразу при касте
  - `on_hit` - при попадании снаряда
  - `on_end` - в конце анимации
- **Задержка урона** - дополнительная задержка в мс
- **Задержка между ударами** - для мульти-хит умений
- **Задержка звука** - синхронизация со звуком
